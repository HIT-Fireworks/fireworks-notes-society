# 资料树与课程关系

本项目中，课程代码与资料仓库是一对一关系：一门课程只关联一个资料仓库，课程元数据也由该资料仓库维护。资料文件不与课程代码建立持久关联，课程页面展示其唯一资料仓库的资料树。

资料树只投影预设资料分类目录中的文件：教材、笔记、课件、试卷、作业、实验、软件、教程、模板、项目、其他。README、LICENSE、repository.toml、`.github` 等仓库管理文件不进入资料树、资料数量或下载统计。

Git Tree 是资料树的权威来源。构建缓存、SSG 页面内嵌数据、Edge Cache/KV 派生索引都只是指定仓库 commit 的缓存，不是人工维护的文件清单。
