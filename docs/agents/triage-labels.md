# Triage 标签

Matt 工程技能使用以下五种标准 triage 角色；本仓库直接使用同名 GitHub label。

| Matt 角色 | GitHub 标签 | 含义 |
|---|---|---|
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待 Issue 提交者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由无人值守 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或决策 |
| `wontfix` | `wontfix` | 明确不处理 |

处理 Issue 时使用上述标签，不创建同义重复标签。已有 GitHub 默认 `wontfix` 标签继续沿用。
