# 领域文档

本仓库采用单一上下文布局。

## 探索前读取

- 根目录 `CONTEXT.md`：项目领域词汇、关系和不变量。
- `docs/adr/`：与当前工作区域相关的架构决策；目录不存在时无需预先创建。

当前没有 `CONTEXT-MAP.md`，不使用多上下文布局。

## 使用规则

- 新的 Issue 标题、计划、实现和测试名称使用 `CONTEXT.md` 已定义的领域术语。
- 如果需要的概念尚未出现在 `CONTEXT.md`，先确认是项目真正的领域缺口，还是实现层临时命名。
- 如果用户用词与 `CONTEXT.md` 冲突，明确指出冲突，不要静默替换术语。
- 如果实现与现有 `docs/adr/` 决策冲突，明确指出对应 ADR，并说明是否需要重新审议。
- `CONTEXT.md` 只记录领域词汇和关系，不写实现细节；实现决策只有在满足“难以逆转、脱离上下文会令人意外、存在真实权衡”时才记录为 ADR。
